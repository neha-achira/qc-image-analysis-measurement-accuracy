# Achira Beta Cartridge QC
Automated QC system for Achira Beta Cartridges (DWG: ACMCTA001, PMMA, 5X stitched PNG microscope images).

---

## Setup (first time only)

1. Install [Python](https://www.python.org/downloads/) (3.10 or newer)
2. Clone or download this repository
3. Double-click **`setup.bat`** — installs all dependencies (opencv, numpy, scipy)

---

## Running the App

Double-click **`run_qc_app.bat`**

Or in Command Prompt:
```
py qc_app.py
```

---

## Calibration (do this before first use, and whenever magnification changes)

Calibration tells the software how many mm each pixel represents. You need one calibration per image type (Holes, Neck, DAB, Mixing).

### Via the GUI (recommended)

1. Open the app (`run_qc_app.bat`)
2. In the **Calibrate** panel at the top:
   - Set **Image type** → e.g. `holes`
   - Click **Browse…** → select your reference image (e.g. `Holes_ch00.png`)
   - Set **# clicks** → `1` is fine to start (higher = more accurate average)
3. Click **🔬 Start Calibration**
4. An image window opens:
   - Click the **left edge** of a hole, then the **right edge** of the same hole
   - Scroll to zoom in, right-drag to pan
   - Press **S** to save
5. A console prompt appears — type the physical size you measured (e.g. `0.5` for a 0.5 mm hole) and press Enter
6. `calibration.json` is saved automatically. The **Current cal:** row in the GUI updates.
7. Repeat for each image type by changing the **Image type** dropdown and selecting the matching reference image.

### Via Command Prompt

```
py calibrate.py calibrate --ref Holes_ch00.png  --feature hole --n_holes 1
py calibrate.py calibrate --ref neck_ch00.png   --feature neck --n_holes 1
py calibrate.py calibrate --ref DAB_ch00.png    --feature hole --n_holes 1
py calibrate.py calibrate --ref Mixing_ch00.png --feature hole --n_holes 1
```

> **Note:** Use Command Prompt (cmd.exe), not PowerShell — the `&` character causes errors in PowerShell.

### Reference sizes (DWG ACMCTA001)

| Image type | Feature  | Nominal size |
|------------|----------|-------------|
| Holes      | hole     | 0.50 mm     |
| Neck       | neck     | 0.20 mm     |
| DAB        | hole     | 0.50 mm     |
| Mixing     | hole     | 0.50 mm     |

## Running QC

1. Open the app (`run_qc_app.bat`)
2. Under **Input**, click **Browse…** and select your batch folder (the folder containing numbered cartridge sub-folders like `1/`, `2/`, etc.)
3. Tick the image types you want to check (Holes, Neck, DAB, Mixing)
4. Click **▶ Run QC**
5. Results appear in the table — green = PASS, red = FAIL
6. A CSV report is auto-saved to the batch folder

### Expected folder structure
```
batch_folder/
    1/
        Holes_ch00.png
        neck_ch00.png
        DAB_ch00.png
        Mixing_ch00.png
    2/
        ...
```

## Troubleshooting

**App window closes immediately**
Run `setup.bat` first to install dependencies. Then open Command Prompt in the folder and run `py qc_app.py` to see the error message.

**"No module named cv2" or "No module named scipy" error**
Run `setup.bat` first — it installs all three packages automatically.
Or install manually in Command Prompt:
```
py -m pip install opencv-python numpy scipy
```

**Use Command Prompt, not PowerShell**
The `&` character used in some commands is not allowed in PowerShell. Always use cmd.exe for running `.bat` files or chaining commands.

**Calibration not found**
Run calibration for each image type before running QC. The `calibration.json` file must exist in the same folder as `qc_app.py`.
